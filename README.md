\# Student Database Backend



A FastAPI-based Student Database Management System.



\## Features



\- Create students

\- View students

\- Update students

\- Delete students

\- Department filtering

\- Student data validation

\- Duplicate email protection

\- SQLite database persistence



\## Tech Stack



\- Python

\- FastAPI

\- SQLAlchemy

\- Pydantic

\- SQLite
